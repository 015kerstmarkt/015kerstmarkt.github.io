# 015Kerstmarkt app

Mini-app voor de 015Connect Kerstmarkt: plattegrond, todo's voor tieners en "Mijn kerstmarkt-POV" (foto's en filmpjes).

- `index.html` is de app voor bezoekers.
- `beheer.html` is voor het team: fotomuur voor een scherm, alle foto's, de mutsenloting en een QR-poster. Hiervoor is de beheersleutel nodig.

Teksten, prijzen, todo's en pinnen op de kaart pas je aan in het blok `CONFIG` bovenaan het script in `index.html`.

Foto's en filmpjes komen via een kleine uploadserver (Cloudflare Worker) in een privé-repo terecht; ze staan niet in deze openbare repo.
